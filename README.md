# 🐍 Neon Cyber Snake Game
A neon-themed Snake Game built using HTML, CSS, and JavaScript.

### Features
- Neon cyberpunk design
- Keyboard and mobile touch controls
- Score and high-score tracking
- Bonus food and sound effects
- Pause, restart, and speed selection

### Technologies
HTML5 | CSS3 | JavaScript | Canvas API

### How to Run
Download or clone this repository and open `index.html` in your browser.
